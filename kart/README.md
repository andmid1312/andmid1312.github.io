# 8BIT STORE KART

Racing-spel för Love & Sigge.

Förare: Ferdi, Annie, Balto, Michael, Bobban, Sigge, Love, Mila.

Love och Sigge använder de riktiga fotona på väljskärmen.

**Spela:** https://andmid1312.github.io/kart/

Kontroller: piltangenter / A-D, Space = boost, eller touch-knappar.

Nytt i denna version:
- AI-motståndare
- Kollisioner + SKÖLD-item
- Bättre väg med kurva
- Boost-partiklar
- Mål-overlay med placering
- Tangentbord + hold-styrning

Lägg assets/sprites/ och assets/*.jpg bredvid index.html för full grafik.
